# 公开范围

本仓库是单独创建的展示工程；没有复制原项目目录或 Git 历史，没有从内部版本删除少量文件后整体发布。

## 允许公开

- 项目问题、使用场景与高层职责架构。
- 独立编写的 FastAPI / React 演示代码。
- 人工虚构的示例资料和预置回答。
- 使用这些虚构样例重新生成的界面截图。
- 对公开演示代码的测试、依赖锁和 CI 定义。

## 不包含

- 核心检查规则、评分公式、权重和判断阈值。
- 模板组合、规范适用与项目规则映射等内部业务逻辑。
- 模型提示词、原请求、原返回、失败原始记录与费用账本。
- 客户、企业及员工个人资料，简历文件、联系方式或内部路径。
- 原标书、招标与答疑材料、图纸、规范原文、审核结果。
- 数据库、向量索引、知识库、模型权重、密钥、Cookie、Token。
- 内部工作目录、归档、服务配置及原 Git 历史。

## 截图约定

截图必须来自本仓库的人工场景。不要直接用生产截图做遮挡：未遮住的项目名、编号、原文、浏览器地址与文件路径仍可能泄露信息。

## 后续更新

继续维护独立目录；只提交审查过的展示文件。`.gitignore` 是补充措施，不能代替对 Git 索引和历史的检查。新增后端能力也应保持演示数据和内部系统隔离。
